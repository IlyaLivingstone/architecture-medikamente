# Реестр программных и аппаратных средств защиты данных

Сводка того, что нужно закупить, развернуть или настроить. Этап указан относительно плана
из описания работы: **MVP** — промежуточное состояние через пару месяцев, **To-Be** —
целевое состояние через год.

## Программные средства

| Средство | Назначение | Какие данные защищает | Состояние | Этап |
|---|---|---|---|---|
| HashiCorp Vault | хранение ключей и секретов, выдача по API | ключи шифрования, секреты сервисов | at rest, in use | MVP |
| PostgreSQL TDE | прозрачное шифрование базы (AES-256) | все классы в операционной БД | at rest | MVP |
| pgcrypto / шифрование колонок | шифрование отдельных полей | диагнозы, паспорта, ИНН, СНИЛС | at rest | MVP |
| BitLocker / LUKS | полное шифрование диска | всё, что лежит на серверах и ноутбуках | at rest | MVP |
| SSE-KMS для объектного хранилища | шифрование сканов и вложений | медкарты, анализы, паспорта | at rest | MVP |
| Шифрование резервных копий | защита бэкапов | все критичные данные | at rest | MVP |
| TLS-терминация (nginx) | шифрование каналов, TLS 1.3 | весь трафик | in transit | MVP |
| API Gateway | валидация контрактов, mTLS, rate limit | данные внешних интеграций | in transit | MVP |
| Keycloak (IAM, SSO) | аутентификация, MFA, роли | учётные данные, доступ ко всем системам | at rest, in use | MVP |
| Policy Decision Point | RBAC и ABAC, проверка на каждом запросе | PII, медданные, платежи | in use | MVP |
| Сервис токенизации | замена реквизитов и идентификаторов токенами | платёжные реквизиты, идентификаторы пациентов | at rest, in use | MVP |
| Процессор логов с маскированием | очистка логов от персональных данных | логи всех сервисов | in use | MVP |
| Сканер секретов | поиск ключей и паролей в коде | секреты, учётные данные | at rest | MVP |
| Аудит-лог приложения | журнал чтения, изменения и выгрузки | медданные, платежи, кадры | in use | MVP |
| SIEM | корреляция событий, алерты, разбор инцидентов | события доступа | in use | MVP |
| DLP | контроль выгрузок, файлов и почты | PII, медданные, кадровые документы | in transit | MVP |
| Сервис сроков хранения и удаления | автоудаление по истечении срока | PII, медданные, сканы | at rest | To-Be |
| Data Catalog и Data Lineage | учёт тегов и пути данных | аналитические наборы | at rest | To-Be |
| Сервис обезличивания | псевдонимизация и обобщение перед аналитикой | наборы для BI/ML/AI | in use | To-Be |
| Сканер уязвимостей | поиск уязвимостей в образах и зависимостях | инфраструктура целиком | — | To-Be |
| EDR на рабочих станциях | защита конечных устройств сотрудников | локальные файлы и доступы | in use | To-Be |

## Минимальный набор для MVP

Это то, без чего нельзя запускать портал пациента и первый этап миграции:

1. Vault для ключей и секретов.
2. TDE и шифрование отдельных колонок в операционной БД.
3. FDE на серверах и рабочих станциях.
4. Шифрование объектного хранилища и резервных копий.
5. TLS 1.3 на всех каналах, mTLS для интеграции с лабораторией.
6. Keycloak с MFA и RBAC, ABAC для медданных.
7. Токенизация платёжных реквизитов.
8. Аудит-лог и SIEM с базовым набором правил.
9. DLP на файловом хранилище и почте.
10. Проверки секретов и тегов в CI.

## Что добавляется в целевом состоянии

1. Сервис сроков хранения и удаления по запросу пациента.
2. Каталог данных и прослеживаемость (Data Lineage).
3. Сервис обезличивания для аналитического контура.
4. HSM для мастер-ключей.
5. PAM jump host и запись административных сессий.
6. EDR на рабочих станциях.
7. Иммутабельное хранилище для резервных копий.
8. Автоматические проверки политик в сборочном конвейере.
