# Задание 1. Анализ безопасности системы

Кейс — компания «Медикаменте»: медцентр с одним офисом, весь учёт ведётся руками в Excel,
сканах и 1С. Задача этого задания — разобрать, как данные ходят по компании сейчас, найти
проблемные места и предложить, чем их закрывать.

## Что лежит в папке

| Файл / папка | Что внутри |
|---|---|
| `DFD_AS-IS/` | 11 диаграмм потоков данных: контекст, 7 процессов и 3 декомпозиции, как есть сейчас |
| `DFD_TO-BE/` | Те же диаграммы, но с мерами защиты, которые нужно добавить на каждом потоке |
| `02_Список_проблем.md` | Аудит текущего состояния: где и почему данные не защищены |
| `03_Данные_и_способы_защиты.md` | Какие данные требуют защиты и каким способом |
| `04_Механизм_тегирования.md` | Как размечать данные тегами и чем это автоматизировать |
| `05_Инструменты_и_меры.md` | Итоговый набор инструментов и мер по процессам |

## Как читать диаграммы

У элементов единые идентификаторы: `Pn` — процесс, `Dn` — хранилище, `En` — внешний субъект
(человек или система). Один и тот же объект на разных диаграммах имеет один и тот же номер —
по нему можно ссылаться в тексте, например «поток P6 -> D7». Номера диаграмм совпадают с
номерами процессов: `DFD_4_Лаборатория анализов` содержит процессы P5 и P6.

Расшифровка обозначений:

- фигура человечка — внешний участник процесса;
- овал с номером `Pn` — процесс (действие над данными);
- цилиндр с номером `Dn` — хранилище данных;
- прямоугольник с номером `Dn` — файл, с номером `En` — внешняя система;
- красная пунктирная стрелка — поток, по которому идут конфиденциальные данные;
- `[PII]`, `[PHI]`, `[FIN]`, `[HR]`, `[CONF]` — класс данных в потоке;
- красный бейдж `#N` — проблемное место, номер совпадает с разделом `02_Список_проблем.md`.

Подпись потока состоит из двух строк: что за данные передаются и какая операция с ними
происходит.

В AS-IS диаграммах показано, как всё устроено сейчас. В TO-BE у каждого потока две части:
подпись потока описывает целевую операцию (например, не «передача по OLE», а «проводка по
API»), а жёлтая плашка, соединённая с подписью пунктиром, — меру защиты, которая применяется
именно на этом этапе. Если хранилище в целевом состоянии уходит, это указано в скобках в его
подписи, например «Excel кассира (выводится из оборота)».

Нумерация файлов в папке начинается с `02_`: `01` — это сами диаграммы, вынесенные в
отдельные папки `DFD_AS-IS` и `DFD_TO-BE`.
